# CardOS

This project aims to over engineer card games and explore the limits of JavaScript features.

Please have a look and feel free to contribute (I need help), I am absolutely sure I made something bad in [what I call the kernel](packages/kernel/README.md)

# Project Overview

This repository is organized as a [PNPM workspace.](https://github.com/pnpm/pnpm)

You can run and verify the integrity of any package with the `tsx` dev dependency like so:

```bash

pnpm install
pnpm exec tsx packages/.../src/index.ts
```
