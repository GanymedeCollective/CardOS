# Card

This is a minimal card module that aims to model a basic card.

It includes the `orientation` (recto/verso) feature that is indeed not an absolute universal feature of card games, but it is considered widespread enough for it to be present at the root of such a module.

# Pile

This is a generic core module that aims to model a regrouping of things.
Those things could obviously be cards, but this object should work with anything `stackable` (tokens, dices, etc.)
